# 01. 약물감시라는 일

> FlyGate 시리즈 1편. 도메인이 처음인 분을 위한 편이지만, 이미 아시는 분께는 뒤쪽
> "여덟 항목을 채워 봤더니" 절부터가 본론입니다.

## 한 건의 보고가 생기는 순간

62세 여성이 난소암으로 니라파립을 먹습니다. 4주째 혈소판 수치가 38,000/μL로 떨어집니다.
약을 끊자 2주 뒤 142,000/μL로 돌아옵니다.

의사가 이걸 보고하면 이때부터 이 한 건이 **이상사례 보고**가 됩니다.

여기서 용어를 하나 짚고 갑니다. 이상사례(adverse event)는 "약을 쓴 뒤 생긴 좋지 않은 일"이고,
이상반응(adverse reaction)은 "그중 약이 원인이라고 볼 만한 것"입니다. 보고가 들어올 때는
전자이고, 후자인지는 따져 봐야 압니다. 이 둘을 섞는 것이 이 분야에서 가장 흔한 오해입니다.

## 흐름 여섯 단계

국내 기준으로 이렇게 갑니다.

```
1. 보고            의사, 약사, 소비자가 서식에 적어 보낸다
2. 인과성 평가      약이 원인인지 사례마다 따진다
3. 신호 찾기        쌓인 보고에서 통계로 수상한 조합을 고른다
4. 실마리정보 알리미  안전관리원이 식약처에 알린다
5. 식약처 조치      허가사항 변경 명령, 안전성 서한
6. VigiBase 갱신    WHO 국제 데이터베이스로 올라간다
```

2번이 병목입니다. 지역의약품안전센터 28곳의 평가자가 개별 사례마다 인과성을 매깁니다.
사람이 읽고 판단합니다.

## 왜 이 판단이 어려운가

인과성 척도를 만든 Naranjo 본인의 1981년 논문에 그 숫자가 있습니다. 의사 2명과 약사 4명이
이상반응 63건을 **척도 없이** 독립 판정했더니 일치가 38~63퍼센트, 카파 0.21~0.40이었습니다.
카파는 우연히 맞는 정도를 빼고 잰 일치도라 0.21~0.40이면 "약간 일치" 수준입니다.
척도를 쓰게 하자 일치가 83~92퍼센트, 카파 0.69~0.86으로 올랐습니다.

즉 같은 도구를 쥐여 주면 맞고 도구가 없으면 갈립니다. 도구를 바꿔도 갈려서, 의심 이상반응
399건을 WHO-UMC로 보면 53.3퍼센트가 "확실"인데 Naranjo로 보면 96.74퍼센트가 "가능성 높음"이
됩니다. 판정의 상당 부분이 사례가 아니라 어느 체계를 썼는지에서 나온다는 뜻입니다.

이것이 AI를 붙이기 어려운 진짜 이유입니다. 모델 판정을 무엇과 대조해 믿을지가 먼저
정해지지 않습니다.

## 쓰는 도구가 셋인데 섞으면 안 된다

국내 실무에서 쓰는 것이 셋입니다. 등급 이름이 서로 달라 섞어 쓰면 안 됩니다.

### WHO-UMC 기준 (서술형 6등급)

확실함 / 상당히 확실함 / 가능함 / 가능성 적음 / 평가 곤란 / 평가 불가.

넷을 봅니다. 시간 관계가 타당한가, 다른 약이나 질환으로 설명되는가, 끊었을 때 좋아졌는가,
다시 줬을 때 재발했는가.

재투여 정보가 없으면 "확실함"까지 못 갑니다. 상당히 확실함이 상한입니다.

### 한국형 인과성 평가 알고리즘 ver 2.0 (점수형)

여덟 항목을 더합니다. 최고 19점, 최저 -13점입니다.

| 항목 | 배점 |
|---|---|
| 시간적 선후관계 | 합당 +3, 모순 -3, 정보 없음 0 |
| 감량 또는 중단 | 중단 후 호전 +3, 무관한 경과 -2, 시행 안 함 0 |
| 이상사례의 과거력 | 예 +1, 아니오 -1, 정보 없음 0 |
| 병용약물 | 단독 설명 불가 +2, 단독 설명 가능 -3, 상호작용 +2 |
| 비약물요인 | 설명되지 않음 +1, 설명됨 -1, 정보 없음 0 |
| 약물에 대해 알려진 정보 | 허가사항 반영 +3, 증례보고만 +2, 알려진 바 없음 0 |
| 재투약 | 재발함 +3, 재발하지 않음 -2, 안 함 0 |
| 특이적인 검사 | 양성 +3, 음성 -1, 미상 0 |

12점 이상 확실함, 6~11 가능성 높음, 2~5 가능성 있음, 1점 이하 가능성 낮음.

### Naranjo Scale (점수형, 조심할 것)

그런데 여기서 함정 하나에 실제로 걸렸습니다.

공유받은 국내 자료의 Naranjo 표는 열 항목을 전부 "예 +1, 아니오 0"으로 적어 두었습니다.
원 논문(Naranjo 등, 1981)은 다릅니다. 항목마다 배점이 다르고 음수가 있습니다.

| 항목 | 자료에 적힌 것 | 원 척도 |
|---|---|---|
| 투여 후 발생했나 | 예 +1 | 예 +2 |
| 재투여 시 재발했나 | 예 +1 | 예 +2, 아니오 −1 |
| 다른 원인이 있나 | 예 +1 | 예 −1, 아니오 +2 |
| 위약에도 나타났나 | 예 +1 | 예 −1, 아니오 +1 |

자료에 실린 대로 구현하면 Naranjo를 구현한 것이 아니므로, 원 논문 배점으로 대조하기
전까지 Naranjo를 시스템에 넣지 않기로 했습니다. 이미 아시는 분이라도 인용한 척도가 원본과
같은지 배점 단위로 대조해 보시기를 권합니다. 국내 교육 자료에 단순화된 판이 꽤
돌아다닙니다.

## 여덟 항목을 실제로 채워 봤더니 일곱이 비었다

말로만 보면 알기 어려우니 실제 보고 한 건으로 해 보겠습니다.

openFDA에서 실제 보고 한 건을 꺼내 한국형 알고리즘 여덟 항목을 채워 봤습니다.
덴마크에서 보고된 니라파립 복용자의 혈소판감소증입니다(safetyreportid 13497451).
판정은 모델이 하고 **점수 합산과 등급은 파이썬이** 했습니다.

| 항목 | 고른 것 | 점수 | 확신도 |
|---|---|---|---|
| 시간적 선후관계 | 정보 없음 | 0 | 0.93 |
| 감량 또는 중단 | 정보 없음 | 0 | 0.35 |
| 이상사례의 과거력 | 정보 없음 | 0 | 0.89 |
| 병용약물 | 정보 없음 | 0 | 0.54 |
| 비약물요인 | 정보 없음 | 0 | 0.95 |
| **약물에 대해 알려진 정보** | **허가사항에 반영** | **+3** | 0.99 |
| 재투약 | 정보 없음 | 0 | 0.99 |
| 특이적인 검사 | 정보 없음 | 0 | 0.97 |

합계 **+3점**, 등급은 **가능성 있음**입니다. 그런데 여덟 항목 중 일곱이 정보 없음이라,
점수는 전부 라벨 기재 여부 한 항목에서 나왔습니다.

### 왜 비었나

입력에는 정보가 있었습니다. 니라파립 투약 구간 다섯 개가 2017-02-08부터 2017-04-20까지
날짜로 들어 있었고 병용약물 다섯 개도 이름이 있었습니다.

그런데도 시간적 선후관계가 "정보 없음"인데, **이상사례 발현일이 공개본에 없어** 투약이
먼저인지 가릴 수가 없기 때문입니다. 조치 코드가 전부 6(해당 없음)이라 중단 여부도 모릅니다.

병용약물 항목의 확신도가 0.54로 가장 낮게 나온 것도 같은 맥락으로 읽힙니다. 약 이름만 있고
용량과 기간이 없어 단독으로 설명되는지 판단할 근거가 없는 상태를 모델이 그대로 드러낸
것입니다.

### 그래서 어떻게 쓰나

그래서 점수만 떼어 인용하면 안 됩니다. "+3점, 가능성 있음"은 약이 무고해서 나온 값이
아니라 **정보가 없어서** 나온 값이고, 둘은 전혀 다른 이야기입니다. 그래서 등급 옆에
**빈 항목 수를 함께 적기로** 했습니다. "가능성 있음(8항목 중 7개 정보 없음)"이라고 쓰면
읽는 사람이 오해하지 않습니다.

시작하기 전에 필드 보유율을 알아 두는 것도 도움이 됩니다. 니라파립과 혈소판감소증 보고 1,065건에서
투약 시작일이 있는 것이 828건, 중단 후 호전 여부가 예 또는 아니오인 것이 700건,
**재투여 필드가 있는 것은 168건**입니다. 재투약 항목은 대부분 0점으로 들어갑니다.

## 정답 데이터가 없다

인과성 평가를 학습하거나 검증하려면 "사람이 매긴 정답"이 필요합니다. 찾아본 결과입니다.

| 데이터 | 인과성 평가 결과 | 경과 서술 | 접근 |
|---|---|---|---|
| FAERS (openFDA) | 없음 | 없음 | 즉시 |
| EudraVigilance 공개본 | 없음 | 없음 | 즉시 |
| VAERS, MAUDE | 없음 | **있음** | 즉시 |
| KAERS 원시자료 | **있음** | 미확인 | 신청 후 한 달 이상 |
| 증례 보고 논문 | 일부 | 있음 | 즉시 |

FAERS를 "정답"이라 부를 수 없습니다. 공개본에 인과성 평가 필드가 아예 없습니다.

대신 쓸 수 있는 것이 구조화 필드입니다. `drugcharacterization`(의심/병용/상호작용),
`actiondrug`(중단, 감량), `drugadditional`(중단 후 호전), `drugrecurreadministration`(재투여
시 재발), `reactionoutcome`(결과)이 한국형 알고리즘 항목과 그대로 대응합니다.

즉 알고리즘 점수의 일부는 기계적으로 채울 수 있습니다. 다만 사람 판정과 맞는지는
따로 확인해야 하고, 그 확인을 할 공개 데이터가 지금은 없습니다.

## 초심자를 위한 요약

- 이상사례와 이상반응은 다릅니다
- 인과성 평가 도구가 여럿이고 등급 이름이 달라 섞으면 안 됩니다
- 척도 없이 판정하면 사람끼리도 잘 안 맞습니다(카파 0.21~0.40). 척도를 쓰면 올라갑니다
- 공개 데이터로는 알고리즘 여덟 항목 중 대부분이 빕니다

## 이미 아시는 분께

- 인용하는 척도의 배점을 원 논문과 대조하세요. 단순화된 판이 돌아다닙니다
- 점수를 인용할 때 빈 항목 수를 같이 적으세요
- FAERS 구조화 필드와 한국형 알고리즘 항목의 대응표를 만들어 두면 자동 채움이 됩니다
- 사람 판정 정답이 필요하면 KAERS 원시자료 신청이 사실상 유일한 길입니다(한 달 이상)
