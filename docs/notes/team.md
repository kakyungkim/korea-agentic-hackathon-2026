## 주제 후보

1. **약물감시 시그널 트리아지 (PharmaSignal).** 팀장이 만들던 것. 도구 3종과 크리틱, 샌드박스가 동작한다. 팀원 한 분이 약물감시에 관심을 밝혔다.
2. **초파리 뇌 아틀라스 기반 신약개발 플랫폼.** 팀원이 이미 데모를 구현해 두었다(drug.flybrain.kr). 초파리의 먹이 탐색 반응을 단백질과 신약 후보물질의 결합력으로 치환해, 결합력이 높은 후보에 초파리가 모이는 방식이다. 사회관계망에서 화제가 되어 주목을 끌기 좋다는 것이 제안 이유다.
3. **Jev 접목.** typesafe ai가 낸 모델로, 자기회귀 방식이 아니고 RLCD 강화학습을 썼다. 언어를 생성하는 대신 선택, 점수, 예/아니오 같은 판단을 빠르게 한다고 한다. 팀원이 PharmaSignal 구조에 얹는 안을 제안했다. **성능과 비용 주장(프런티어 LLM 대비 200배 빠르고 400배 저렴)은 아직 출처를 확인하지 않았다 [unverified].**

주제는 다섯 명 의견을 모아 정하기로 했다. 팀장이 별도 세션에서 초파리와 Jev 두 주제의 계획을 먼저 짜기로 했다.

## 먼저 확인해야 할 것

1. **오프라인 본선 참석.** 2026-10-07 One-day 해커톤이 오프라인이다. 팀원 한 분이 해외에 있어 참석할 수 없다. 팀원 전원 참석이 필요한지, 일부만 나가도 되는지 주최 측에 확인해야 한다. 본선 진출 발표가 10-02이므로 그 전에 물어 두는 편이 낫다. 패스트캠퍼스 고객센터는 평일 10시에서 18시까지 운영한다.
2. **시차.** 보스턴은 한국시간보다 13시간 또는 14시간 느리다. 해당 팀원이 가능하다고 밝힌 시간은 한국시간 평일 오전, 또는 저녁 10시 이후다. 회의 시간을 그 안에서 잡는다.
3. **Jev의 실체와 접근 방법.** 모델 제공처, 가격, API 접근 방법, 그리고 NVIDIA 해커톤 심사에서 어떻게 읽힐지 확인이 필요하다. 심사 항목이 NVIDIA Agent 기술 활용 심도라, 다른 회사 모델을 핵심에 두면 불리할 수 있다. 판단 단계에만 보조로 쓰고 주 경로는 Nemotron으로 두는 구성을 검토한다.

공통 하네스(NeMo Agent Toolkit 작성자와 크리틱 분리), 크리틱 검증 구조, OpenShell 정책과 차단 로그,
평가 방식(`nat eval` 적발률)은 어느 주제에도 그대로 쓴다. 도메인 도구만 갈아 끼우면 된다.
약물감시 도구 3종과 케이스 3건 수치는 주제가 바뀌면 쓰지 않는다.
