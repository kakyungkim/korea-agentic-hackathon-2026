### DLI 강좌

진도가 0퍼센트에서 오르지 않아 강좌 앱 소스(`scripts/_activity_runtime.js`, `_activity.js`)를
읽고 원인 셋을 가렸다. 화면에 단서가 없어 혼자서는 찾기 어려운 것들이다.

1. 진도 증거가 `sessionStorage` 에 있어 탭을 닫으면 지워진다. 앞서 `localStorage` 로 적었던
   기록은 오류였고 정정했다
2. 원격 기록이 기본으로 꺼져 있다. 상단 바의 달리는 사람 버튼에서 켠다
3. **첫 화면에서만 키를 저장하면 `01a` 가 영원히 안 찍힌다.** `nemoclaw:api-key-verified` 를
   쏘는 곳이 `01a-loop.html` 하나뿐이고, 진도는 첫 체크포인트부터 연속이어야 오른다

이 순서로 풀어 50퍼센트에 도달했다. 다만 **Activity API 가 응답하지 않아 서버에는 기록이
남지 않았다.** 화면에 `The Activity API is unavailable` 이 떴고 이어서 `Connecting to the
Activity API.` 로 바뀌었다. 확인이 필요하다.

모듈 3, 4 실습 환경은 Brev 말고 **강좌 페이지의 `START` 로 DLI 무료 환경(5시간)** 을 띄우는
