# 대비: 팀원 이탈과 초파리 자산 제거

2026-09-25 작성. 오프라인 본선에 전원 참석이 필요하다고 나오면 팀원 A 와 D 가 빠질 수 있다.
둘 다 해외 거주다. 그때 무엇이 무너지고 무엇을 미리 해 둘지 적는다.

## 먼저: 시점을 가른다

**온라인 사전 챌린지(9/28 제출)는 영향이 없다.** 다섯 명이 실제로 기여했고 폼도 각자 낸다.
참석 문제는 본선(10/7)의 문제다. 그러니 제출물을 지금 고칠 이유가 없다.

| 시점 | 상태 | 할 일 |
|---|---|---|
| 9/28 제출 | 다섯 명 그대로 | 아무것도 바꾸지 않는다 |
| 9/28 오전 문의 | 전원 참석 필요 여부 확인 | 주최 측에 묻는다 |
| 10/2 본선 발표 | 진출 여부 확정 | |
| 10/7 본선 | 참석 가능 인원만 | 아래 대비가 필요해지는 시점 |

**즉 지금 하는 대비는 제출물을 바꾸는 것이 아니라, 나중에 바꿀 수 있게 만들어 두는 것이다.**

## 이탈의 영향

팀원 A 가 빠지면 FDDD 자산을 계속 쓸 근거가 약해진다. 공개 데이터라 인용 자체는 가능하나
팀 저작물로 내세우기는 어렵다. 걸리는 것이 넷이다.

| 자산 | 의존 | 빠지면 |
|---|---|---|
| ~~과잉해석 규칙 10종~~ **3종** | FDDD `notes` 8항목 | **2026-09-25 문헌 이중 귀속으로 10종에서 3종으로 줄였다.** 남은 셋은 종 차이, 입력 동일성, 근거 범위이고 도구 문서 수준의 상식이라 FDDD 없이도 주장할 수 있다 |
| `vina_reference` 도구 | `drug.flybrain.kr` 조회 | 케이스의 Vina 수치가 사라진다 |
| 케이스 브리프 | Vina -10.178, -7.967, `role` 원문 | 두 경로 대조의 절반 |
| 이름 FlyGate | 초파리 훅 | 초파리가 없으면 이름이 겉돈다 |

팀원 D 가 빠지는 쪽은 비용이 작다. 고유 자산이 없고 맡은 일이 재측정과 README 다듬기다.

## 대비 1. 규칙의 출처를 문헌으로 이중 귀속 (완료)

**FDDD 의 notes 는 도킹 분야에서 알려진 한계를 다시 적은 것이고 같은 내용이 동료심사 문헌에 있다.**
그러니 출처를 문헌으로 함께 달면 FDDD 가 빠져도 규칙이 산다. 논문으로 갈 때도 근거가 강해진다.

| 규칙 | 문헌 귀속 |
|---|---|
| 교차 타깃 순위 금지 | Warren 등 2006, J Med Chem 49(20):5912 |
| 친화도 환산 금지 | Pantsar와 Poso 2018, Molecules 23(8):1899 |
| 종점 혼합 규칙 | Kalliokoski 등 2013, PLoS ONE 8(4):e61007 |
| RMSD 기준 명시 | PoseBusters 2024, Chem Sci 15(9):3130 |
| 수렴 주장 금지 | AutoDock Vina 공식 FAQ + 우리 실측 |
| DiffDock 계열 4종 | Corso 등 2023 원 논문 + NVIDIA 문서 |

문헌이 없는 것은 억지로 붙이지 않고 그대로 둔다. 종 차이, 입력 동일성, 근거 범위 셋이다.
도구 문서 수준의 상식이라 FDDD 가 빠져도 주장하는 데 문제가 없다.

**완료했다. FDDD 단독 의존이 10종에서 3종으로 줄었다.** 문헌 귀속 11종, 없음 4종이다.
`overclaim_rules.FDDD_INDEPENDENT_RULE_IDS` 로 문헌이나 NVIDIA 문서로 서는 12종을 꺼낼 수 있다. 자세한 것은
`docs/notes/paper-plan.md` 의 규칙별 문헌 뒷받침 강도 표.

## 대비 2. DiffDock 만으로 서는 케이스

Vina 가 빠져도 **케이스의 요지는 그대로 선다.** 확인해 둔 것이 있다.

| | 경로 A (PARP1) | 경로 B (응고인자 Xa) |
|---|---|---|
| DiffDock 신뢰도 | 0.761, 0.693, 0.515 | **-0.172, -0.205, -0.665** |
| BindingDB 참조 | 레코드 7,311건 | 없음 |
| 사람 근거 | 라벨 기재, PRR 9.13 | 화합물 단위라 타깃을 못 가림 |

**DiffDock 수치는 우리가 직접 부른 것이고 음수 신뢰도도 우리 관측이다.** 구조는 RCSB 에서
직접 받는다. 즉 Vina 없이도 "같은 화합물, 두 경로, 한쪽만 실험 근거가 있다" 가 성립한다.

잃는 것은 둘이다. 도구 둘을 견주는 대조와 `role` 원문 인용이다. 전자는 아쉽고 후자는
문헌 귀속으로 대체된다.

**미리 해 둘 것.** `scripts/run_case_demo.py` 에 `--no-vina` 플래그를 두어 Vina 단계를
건너뛰고도 브리프가 나오게 한다. 지금 하면 20분이고 나중에 급할 때 하면 두 시간이다.

## 대비 3. 이름

초파리가 빠지면 FlyGate 가 겉돈다. **PoseGate** 를 대안으로 둔다. 포즈와 관문이고
검증에 무게가 실린다. 검색에서 생물정보 도구 충돌이 없다.

바꾸기 쉽게 두 곳에만 박아 두었다.

- `scripts/make_figures.py` 의 `PROJECT_NAME` 상수
- `policies/flydock.yaml` 파일명

그 밖에 `README.md`, `docs/submission-flygate.md`, 영상 나레이션 첫 문장과 슬라이드 제목에
이름이 들어간다. 문자열 치환으로 30분이면 된다.
