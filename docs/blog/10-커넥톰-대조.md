# 비유인가 기여인가: 커넥톰 대조 실험

[시리즈 색인](00-시리즈-색인.md) · 앞 편은 [초파리 뇌를 코드로 옮기기](09-커넥톰-데이터.md)입니다.

앞 편에서 커넥톰이 화면에만 쓰인다고 적었습니다. 그럼 실제로 쓰이게 만들 수는 없나.
해 볼 만하고, 결과가 음성일 가능성이 높습니다. 이 편은 그 실험을 어떻게 설계했는지입니다.

## 발상: 초파리 후각 회로가 하는 일

초파리가 냄새를 구분하는 방식이 재미있습니다.

```
후각 수용체 50종  →  (무작위에 가까운 희소 연결)  →  케니언 세포 2,000개
                     여기서 소수만 살아남는다(승자독식)
```

입력 차원은 작은데 출력 차원은 훨씬 큽니다. 그리고 출력에서 소수만 활성화됩니다.
차원을 늘리고 희소하게 만들면 서로 다른 냄새가 서로 더 멀어집니다.

이 원리를 알고리즘으로 옮긴 것이 FlyHash입니다(Dasgupta 등, Science 2017). 무작위 희소
투영으로 차원을 늘리고 상위 몇 퍼센트만 남기는 해시인데, 유사도 검색에서 잘 듣습니다.

그렇다면 무작위 투영 대신 실제 초파리 배선을 쓰면 더 나을까요.

## 설계

특징 벡터를 실측 배선으로 투영합니다.

```
특징 (PRR, ROR₀₂₅, IC₀₂₅, 카이제곱, 보고 건수, 라벨 상태)
   ↓  실측 가중치로 투영 (encode → reflex·memory 부분그래프)
희소 승자독식 코드
   ↓  선형 판독
점수
```

과제는 SIDER 참조 세트 **6만 4,796쌍**입니다. 데이터는 앞 편의 CSR 파일 그대로입니다.
**CPU만 쓰고 API 비용이 0원**입니다.

## 대조군 넷

여기가 이 실험의 전부입니다. 대조가 없으면 아무것도 잰 게 아닙니다.

| 대조 | 무엇을 가르나 |
|---|---|
| **차수 보존 재배선** 100회 | 실측 배선의 **구체적 연결 패턴**이 기여하는가 |
| 밀도 맞춘 무작위 희소 투영 | 커넥톰 대신 FlyHash 원본을 쓰면 어떤가 |
| 조밀 무작위 투영 | 희소성 자체가 기여하는가 |
| **투영 없음** | 투영이 애초에 필요한가 |

첫 번째가 결정적입니다. **차수 보존 재배선**은 각 뉴런이 가진 연결 개수는 그대로 두고 상대만
무작위로 바꾸는 것입니다(configuration model).

왜 이게 중요한가 하면, 실측 배선이 무작위보다 좋게 나왔다고 해도 그 이유가 **연결 패턴**일
수도 있고 그냥 **차수 분포**일 수도 있기 때문입니다. 차수 분포는 재배선해도 유지되니,
재배선 100회 분포 안에 실측이 들어가면 패턴은 기여하지 않는다는 뜻입니다.

네 번째가 가장 중요할 수 있습니다. 투영 없이 특징을 바로 판독에 넣은 것과 실측이 같으면,
커넥톰뿐 아니라 투영 자체가 불필요합니다. 이 줄을 빼면 "커넥톰이 무작위보다 좋다"는 결론을
내면서 정작 둘 다 아무것도 안 하는 것일 수 있습니다.

귀무 AUC는 [3편](03-불균형-지표.md)에서 쓴 라벨 뒤섞기 방식을 그대로 씁니다.

## 선행 결과를 먼저 찾았습니다

같은 대조를 유사도 검색에서 이미 한 연구가 있습니다(`FlyHash-Connectome`).
결과가 음성이었습니다.

| 조건 | 값 |
|---|---|
| 실측 커넥톰 | 0.4063 |
| 무작위 | 0.4148 |
| 차이 | **-2.06%** |
| 차수 보존 재배선 대비 중앙값 | **-1.6%** |

실측이 무작위보다 낮았습니다. 결론이 "좋은 fly hash에 커넥톰 데이터는 필요 없다"입니다.

이걸 먼저 찾아 둔 것이 중요합니다. **선행 연구가 음성인 실험을 양성을 기대하며 시작하면
결과를 기다리는 태도가 달라집니다.** 우리가 무엇을 기대하는지 미리 적어 두면 나중에
결과를 읽을 때 자신을 속이기 어렵습니다.

## 결과에 따른 분기를 미리 정했습니다

실험 결과가 나오기 전에 무엇을 할지 정해 두는 편이 낫습니다. 나온 뒤에 정하면 결과에
맞춰 이야기를 짜게 됩니다.

**실측이 재배선 분포를 벗어나면.** 다른 도메인이 그 음성을 뒤집은 것이라 그 자체로 논문이
됩니다. 다음 질문은 어느 부분그래프가 그 이득을 만드는지(외측뿔인지 버섯체인지), 440건
트리아지로도 전이되는지, 같은 파라미터 수의 **학습된** 투영을 이기는지입니다.

**벗어나지 않으면.** 그럴 가능성이 높습니다. 본편 논문 안의 한 절이 됩니다. 두 번째 도메인
확인이라 선행 연구와 함께 인용됩니다. 커넥톰은 시각화로 내려갑니다.

**네 번째 대조가 실측과 같으면.** 투영 자체가 불필요하다는 뜻입니다. **이 줄이 가장
중요합니다.** 우리가 만든 구조의 일부가 아무 일도 안 한다는 것을 우리가 밝히는 것이라서요.

## 왜 음성일 가능성이 높은 실험을 하나

셋입니다.

비용이 0원입니다. CPU만 씁니다. 모델 호출이 없습니다.

논지와 맞습니다. 이 프로젝트는 주장이 근거를 넘지 않게 하는 일을 합니다. **그런 프로젝트가
자기 비유를 스스로 검증해서 기여가 아님을 보이면 프로젝트 전체의 신뢰가 오릅니다.**
반대로 검증하지 않고 화면에 초파리 뇌를 띄워 두면, 앞 편에 적은 12만 회 읽힌 게시물과 같은
자리에 서게 됩니다.

음성 결과가 인용됩니다. "커넥톰 배선을 특징 투영에 써 봤으나 차수 보존 재배선을 넘지
못했다"는 문장은 다음 사람이 같은 일을 반복하지 않게 합니다. 두 도메인에서 같은 방향이면
더 강해집니다.

## 이 편에서 가져갈 것

- **대조군에 "아무것도 안 하기"를 넣으세요.** 정교한 방법끼리만 견주면 둘 다 쓸모없을 때
  그걸 못 봅니다
- **차수 보존 재배선**처럼 구조의 한 성질만 남기는 대조가 가장 많은 것을 가릅니다
- 선행 연구가 음성이면 그걸 먼저 찾아 적어 두세요
- 결과가 나오기 전에 분기를 정해 두세요
- 내 구조가 기여하지 않는다는 결과도 결과입니다
