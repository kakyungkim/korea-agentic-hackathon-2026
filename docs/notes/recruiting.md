## 게시한 글의 방향 (9/24 GPTers 방)

주제를 약물감시로 제시하되 방법 설명은 줄이고, 의료나 제약 현장의 다른 문제도 환영한다고 열어 두었다.
PoC가 있어 빠르게 갈 수 있다는 점을 밝혀 신뢰를 주고, 실무자와 개발자 어느 쪽도 부담 없이 들어오게 문턱을 낮췄다.

## 모집 글 요지 (게시용)

주제는 두 가지 중 팀 구성에 맞춰 정한다. 약물 이상사례 시그널을 공개 데이터로 1차 판정하는 에이전트,
또는 밤새 저장소에서 스스로 실험하고 아침에 증거를 붙인 PR 후보를 올리는 자율 에이전트.
찾는 사람은 파이썬으로 API 연동이나 LLM 도구 호출을 해 본 개발자 1~2명,
약물감시나 RA 실무 경험자, 리눅스 서버 보유자면 더 좋다.
PoC는 이미 돌아가는 상태라 합류하면 바로 이어 붙일 수 있다.

## 문체 규율

커뮤니티 글과 개인 메시지에 실명을 쓰지 않는다. 경력과 역할로만 소개한다.
아는 사이에게 보내는 메시지는 절차나 허락을 묻지 말고 용건을 바로 제안한다.
문지기(방장, 운영자)에게만 승인을 구한다.
