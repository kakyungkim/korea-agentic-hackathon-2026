n_total 쿼리(?limit=1)만 통과. counts=null 이라 PRR/ROR 계산 불가.

원인 (게이트웨이 로그 원문):
  [ocsf] NET:OPEN [INFO] ALLOWED /usr/bin/python3.12(400) -> api.fda.gov:443 [policy:openfda engine:opa]

L4(opa)는 통과하고 L7 프록시가 요청 라인을 거부한다. 도구가 만드는 URL 에
`search=...generic_name:"metformin"` 처럼 따옴표가 인코딩되지 않은 채 들어가기 때문이다.

### 2b. 클라이언트별 대조 (같은 샌드박스, 같은 호스트)
  curl  ?limit=1                                   -> http=200 rc=0
  curl  ?search=...:"metformin"&limit=1            -> curl: (52) Empty reply from server, http=000 rc=52
  curl  ?search=...:%22metformin%22&limit=1        -> http=200 rc=0
  curl  ?limit=1&search=serious:1                  -> http=200 rc=0
  py    ?limit=1                                   -> 200
  py    ?search=...:%22metformin%22&limit=1        -> 200
  py    ?search=...:"metformin"&limit=1            -> RemoteDisconnected
=> 파이썬 문제가 아니다. 따옴표를 %22 로 인코딩하면 curl 과 파이썬 모두 통과한다.

### 2c. 따옴표를 %22 로 바꾼 사본 (성공)
샌드박스 안 사본에만 적용했다(저장소 파일은 건드리지 않았다).
  _drug_clause:     f'{field}:"{quote(...)}"'          -> f'{field}:%22{quote(...)}%22'
  _reaction_clause: f'{REACTION_FIELD}:"{quote(...)}"' -> f'{REACTION_FIELD}:%22{quote(...)}%22'
