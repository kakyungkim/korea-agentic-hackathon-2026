# 초파리 뇌를 코드로 옮기기

[시리즈 색인](00-시리즈-색인.md) · 앞 편은 [구조에서 결합까지](08-bionemo-네-단계.md)입니다.

프로젝트 이름의 Fly가 여기서 옵니다. 그리고 이 편과 [다음 편](10-커넥톰-대조.md)은 짝입니다.
이 편은 데이터를 어떻게 다뤘는지, 다음 편은 **그게 정말 쓸모가 있는지**입니다.

## 커넥톰이 무엇인가

뇌의 배선도입니다. 뉴런 하나하나와 그것들이 어디에 어떻게 연결됐는지를 다 적은 지도입니다.

사람 뇌로는 아직 못 만듭니다. 뉴런이 860억 개쯤 되고 연결은 그보다 훨씬 많습니다.
초파리는 다릅니다. **MaleCNS**는 Janelia FlyEM 등이 공개한 수컷 초파리 중추신경계 커넥톰이고,
뉴런 약 **16만 6천 개**와 그 사이 연결이 다 들어 있습니다. CC-BY 4.0이라 출처를 밝히면
누구나 씁니다.

전자현미경으로 얇게 썰어 찍고, 그 단면들을 다시 이어 붙여 뉴런을 추적한 결과입니다.
**뇌 전체의 배선이 완성된 몇 안 되는 종**입니다.

## 왜 초파리인가

세 가지입니다.

작으면서 복잡합니다. 16만 6천 개는 사람 뇌에 비하면 작은데, 그래도 냄새를 구분하고
학습하고 짝을 찾습니다. **선택과 게이팅이 실제로 일어나는 가장 작은 뇌**에 가깝습니다.

공개돼 있고 라이선스가 깨끗합니다. CC-BY 4.0입니다. 연구용 승인 절차 없이 받아 씁니다.

구조가 눈에 보입니다. 감각 입력이 들어오는 곳, 갈라지는 곳, 기억으로 가는 곳이 해부학적
이름으로 구분돼 있습니다. 화면에 그리면 사람이 알아봅니다.

## 부분그래프로 줄였습니다

16만 6천 개를 브라우저에서 돌릴 수 없습니다. 중앙뇌 부분만 뽑았습니다.

| 항목 | 값 |
|---|---|
| 뉴런 | **49,244** |
| 연결 | **1,051,255** |

`pipeline/connectome/`이 원본에서 이걸 뽑습니다. 그리고 에이전트의 아홉 개 기능 층에
대응시켜 작업이 어디로 갈라지는지 화면에 보여 줍니다.

## 이진 포맷으로 내보냅니다

연결 105만 개를 JSON으로 쓰면 수십 메가바이트가 됩니다. 브라우저에서 파싱하는 데도 시간이
걸립니다. 그래서 **CSR(Compressed Sparse Row)** 이진 포맷으로 씁니다.

CSR은 희소 행렬을 세 배열로 담는 방식입니다.

```
indptr   각 행(뉴런)의 연결이 indices 배열에서 어디부터 시작하는지
indices  연결 상대 뉴런의 번호
data     연결 세기
```

뉴런 i의 연결은 `indices[indptr[i] : indptr[i+1]]`입니다. 슬라이스 하나로 끝납니다.

이진으로 쓰면 브라우저에서 `fetch` 후 `ArrayBuffer`로 받아 `Int32Array`와 `Float32Array`로
바로 씁니다. 파싱이 없습니다. JSON 대비 용량도 작고 로딩도 빠릅니다.

```javascript
const buf = await (await fetch('/data/connectome/edges.bin')).arrayBuffer();
const indptr  = new Int32Array(buf, 0, nNodes + 1);
// 이하 오프셋을 맞춰 indices, data 를 얹는다
```

**오프셋을 헤더에 적어 두세요.** 배열 길이를 코드에 박아 두면 데이터를 다시 뽑을 때마다
코드를 고쳐야 합니다.

좌표도 같이 내보냅니다. 3차원 위치를 `Float32Array`로 담고, 화면에 그릴 때 정밀도가 필요
없어서 소수점을 잘라 용량을 줄였습니다.

## 여기서 멈춰야 하는 지점

과장하지 않고 말하면 이것은 비유입니다.

초파리 뇌가 감각 신호를 전부 처리하지 않고 게이팅으로 걸러 내듯, 부작용 보고를 전부 큰
모델에 넣지 않고 앞단에서 거릅니다. 초파리 회로를 모사한 모델을 돌리는 것이 아닙니다.

커넥톰은 화면에서 구조를 보여 주는 역할이고, 실제 걸러내기는 규칙과 Jev가 합니다.
이 구분을 흐리면 이 프로젝트가 막으려는 바로 그 과장이 됩니다.

## 실제로 있었던 과장

이 경계를 강조하는 이유가 있습니다. 2026년 9월에 어떤 게시물이 12만 회 넘게 읽혔는데,
본문이 이랬습니다.

> 초파리 뇌를 훈련시켜 Rentosertib를 합성하게 했다

그 데모가 쓰는 커넥톰 파일을 직접 받아 봤습니다. **노드 80개, 엣지 1,296개**였습니다.
그리고 그 파일 안에 이렇게 적혀 있었습니다.

> "Not a physiological or whole-brain model."
> "Engineered 8-channel input injection; simplified signed, normalized, leaky tanh rate units."

홍보 문구의 16만 7천 뉴런과 실제로 반응하는 80노드가 다릅니다.

스파이크도 진짜이고 도킹 점수도 진짜인데 "뇌가 합성했다"는 결론만 근거를 넘습니다.
저희가 만든 크리틱이 잡는 것이 정확히 이 구조입니다. 그래서 같은 재료를 쓰면서 같은 말을
하지 않으려고 문서와 화면에 경계를 적어 두었습니다.

## 그런데 정말 비유에 그치나

여기서 질문이 하나 남습니다. **커넥톰 데이터가 실제 판정에 기여할 수는 없나.**

초파리 후각 회로가 하는 일은 냄새 신호를 희소한 코드로 바꿔 구분하기 쉽게 만드는 것입니다.
그 원리를 쓴 알고리즘이 이미 있습니다(FlyHash, Dasgupta 등, Science 2017). 그렇다면 우리
특징 벡터를 실측 배선으로 투영해 보면 어떨까요.

해 보기로 했습니다. 그리고 답이 "아니오"로 나올 가능성이 높다는 것도 미리 알아 두었습니다.
